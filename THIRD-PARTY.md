# Third-party code and attribution

ZoniStation One is licensed **GPL-3.0-or-later** (`LICENSE`). This file lists every part of the
source tree that is derived from someone else's work, what its upstream licence is, and why that is
compatible with the licence above.

The distinction that matters throughout: **implementing a documented behaviour is not derivation.**
Hardware register layouts, cycle counts, lookup tables and the algorithms published in `DOCS/` are
facts about a 1994 console, and every emulator necessarily arrives at the same ones. Copying another
project's *code* is derivation. Only the second kind is listed here.

condition. The obligations that come with it — keep the source available, keep the attribution
headers, license derivative works the same way — are met by publishing this repository under
`LICENSE` with those headers intact.

**Do not strip the attribution headers.** They are the licence condition being satisfied. Removing
them while keeping the code would turn a compliant use into a non-compliant one.

## Written from documentation, not ported

These carry no third-party copyright: each is implemented from the published hardware
specification, cited per line below so any claim can be checked against the source.

| Subject | Source | Notes |
|---|---|---|
| MDEC RLE decode, IDCT, YUV→RGB, mono, zigzag/zagzig tables | `DOCS/macroblockdecodermdec.md:138-158, :192-245, :271-295` | The zagzig table is generated by the documented rule from the documented zigzag table. |
| SPU 4-point Gaussian interpolation and its 512-entry table | `DOCS/soundprocessingunitspu.md:215-291` | Self-checking: the documentation notes at `:295-299` that the real table's groups of four sum to 7F7Fh..7F81h instead of 8000h, and the transcription reproduces exactly that range. |
| SPU noise generator | `DOCS/soundprocessingunitspu.md:534` | Computed from the published parity expression rather than stored as a table, which removes the whole class of transcription error. |

| Memory access timing (`calc_memory_timing_word_cycles`) | `DOCS/memorycontrol.md:37-53, :126-145` | The 1ST/SEQ/MIN arithmetic is the published pseudocode transcribed line for line. |

## Reference clones

`duckstation_ref/` and `pcsx-redux/` are git submodules: this repository records a URL and a commit
hash, and distributes none of their content. They are consulted when the hardware documentation is
ambiguous, and never linked or built into the emulator.

**DuckStation is CC-BY-NC-ND-4.0** as of 2024-09-01. That licence forbids derivative works and
commercial use, and is incompatible with the GPL. No DuckStation code may be copied into this
project. Where a comment mentions DuckStation, it describes a behaviour or an approach — which
carries no copyright — not copied code.

---

## Not included, and not redistributable

No BIOS image, disc image, or other Sony copyrighted material is part of this repository. `roms/`
and `games/` are gitignored. You must supply your own BIOS and your own discs.
