Pipeline — the view no other emulator has

Every bug this project has spent a session on lived between two subsystems, not inside one. This puts the whole chain on one row with live rates, so a stage that stops feeding the next one is visible instead of deduced.

Frame — ops on a time axis

Uploads, draw batches, XA sectors and the display flip against the 20.1 ms frame. "Thirteen columns never arrived" reads off the track directly.

Audio — queue as a first-class signal

Produced against consumed, queue depth over time, and drops. The difference between a DSP bug and a delivery problem is the difference between these two numbers.

The screen is the anchor

It does not become a tab you switch away from. Every mode is arranged under it, so you never lose sight of the machine while reading its instruments — and "Display only" gives it the whole stage when you just want to play.

What stays

Disassembly, registers, breakpoints, watchpoints, VRAM viewer with its decode modes, per-category logs, Lua console — same depth, moved into modes instead of a floating panel grid, with any Lua expression pinnable as a live watch.
